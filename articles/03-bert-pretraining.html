BERT 预训练：MLM 如何让 Encoder 学会双向上下文

拆开输入表示、遮盖目标、训练损失与预训练—微调接口，理解 BERT 真正优化的是什么。

建议阅读：15–25 分钟 · 先理解问题，再检查公式、张量与实验边界。

1. 为什么不能直接预测每个 token 的下一个词

如果每个位置都只预测右侧 token，模型必须遵循因果方向。BERT 的目标是学习可供理解任务使用的双向表示，因此随机选择部分输入位置作为监督目标，让其余可见 token 提供左右两侧上下文。

2. MLM 的 15% 选择规则

原始 BERT 论文从 WordPiece token 中随机选择 15% 作为预测位置。被选中的位置中，80% 替换为 [MASK]，10% 替换为随机 token，10% 保持原 token 不变。损失只在被选中的预测位置上计算。

3. 损失函数与梯度从哪里来

对被选中位置 M，目标是最大化原 token 的条件概率；训练时使用这些位置上的交叉熵之和/平均。未被选中的位置仍通过上下文路径参与前向计算，但不作为该次 MLM 的直接分类目标。

LMLM = − Σi∈M log P(xi | x\M)

4. NSP 是什么，又不是什么

原始 BERT 还使用 Next Sentence Prediction：输入 A 与 B，判断 B 是否为语料中 A 的真实后续句。论文构造 50% IsNext 与 50% NotNext。NSP 是原始训练配方的一部分，不应推广成所有后续 BERT 类模型都必须使用的目标。

5. 从输入到输出的张量路径

Token、Position、Segment embedding 相加并归一化后进入多层 Transformer encoder。每层输出维度保持 H；MLM head 将隐藏状态映射回词表分布，NSP head 使用 [CLS] 表示做二分类。

6. MLM 带来的训练—推理差异

[MASK] 只在预训练中出现，而多数下游文本没有这个符号；80/10/10 规则让模型也见到未遮盖或随机替换位置，缓和但不消除差异。MLM 训练目标也不是自然的逐 token 生成概率分解。

本章的三个结论

  • 先明确模型解决的问题，再解释它的计算结构。
  • 公式必须与输入输出形状、归一化维度和训练目标对应。
  • 示意代码用于验证数据流；论文指标必须回到原始实验条件核对。
