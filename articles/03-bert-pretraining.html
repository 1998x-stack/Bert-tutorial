BERT 预训练：MLM 如何让 Encoder 学会双向上下文

BERT 的核心问题不是“怎样把词遮住”，而是怎样在不让目标词直接泄漏的前提下，让深层 Transformer 表示同时利用左侧和右侧上下文。本篇从 MLM 目标、NSP、训练流程和损失位置完整拆开。

阅读约 24 分钟主题：MLM / NSP / 预训练配置核心问题：模型在哪些位置承担预测损失

1. 为什么标准语言模型有方向

自回归语言模型把序列概率分解为逐位置的条件概率。预测第 t 个 token 时，模型只能读取此前的 token；如果让模型同时读取目标词右侧和目标词自身，而目标词又直接出现在输入中，网络就可能通过信息泄漏轻易复制答案。

BERT 的目标是为理解任务学习深层双向表示。它采用 Cloze 式的 MLM 训练：随机选出一部分 token 作为预测目标，对输入序列中的这些位置做替换，再让双向 Transformer encoder 从剩余上下文恢复原 token。被选中的位置不会总是直接显示为 [MASK]，以减轻预训练与微调时输入分布的差异。

2. BERT 的模型规模

BERT 使用多层双向 Transformer encoder。论文主要报告两种规模：

配置层数 L隐藏维度 H注意力头 A参数量FFN 中间维度
BERT-Base1276812约 110M3072
BERT-Large24102416约 340M4096

论文选择 BERT-Base 的规模与 OpenAI GPT 接近，以便比较架构差异。两者一个关键区别是注意力可见范围：BERT 的 encoder 使用双向 self-attention；GPT 的预训练 Transformer 使用左到右的因果约束。

模型层数、隐藏维度和 head 数是模型配置，不是 MLM 目标本身。改变这些超参数会改变模型容量与计算成本，但不会自动改变损失只在选中位置计算这一训练规则。

3. MLM：选择 15% 的预测位置

原始 BERT 论文在 WordPiece token 化之后，随机选择每条输入序列中 15% 的 token 位置作为预测目标。设这些位置组成集合 M。对每个被选中的位置，训练数据生成器采用以下替换策略：

  • 80%：替换为特殊 token [MASK]。
  • 10%：替换为词表中的随机 token。
  • 10%：保持原 token 不变。

这三个比例必须分清分母：先从整条序列随机选出 15% 的预测位置，再只对这些位置分配 80/10/10。换算到整条序列，约 12% 的所有 token 被替换为 [MASK]，约 1.5% 被随机 token 替换，约 1.5% 保持原样但仍承担预测损失。

为什么不把所有目标位置都替换为 [MASK]？因为微调阶段通常不会出现 [MASK]。随机替换和保持原样让编码器在训练时也需要处理非 [MASK] 输入，缓和预训练与微调之间的差异。

4. 损失函数到底在哪些位置计算

设原始 token 序列为 x_1,…,x_T，M 是被选中的预测位置集合。MLM 头将对应位置的最终隐藏状态映射到词表 logits，再对原 token ID 计算交叉熵。概念上的目标为：

LMLM= −∑i∈M logpθ (xi|x∖M)

实现中常对被选位置的 token loss 求和或按目标 token 数量取平均；关键是监督位置来自 M，而不是整条序列每个位置。

未被选中的 token 仍然参与前向计算：它们提供上下文，影响其他位置的 hidden state 和梯度路径。但在这一次 MLM 目标里，它们不是直接被送入词表分类器计算目标词交叉熵的位置。

“BERT 预测整句话的所有 token”是不准确的。原始 MLM 只在随机选中的位置计算预测损失；这与自回归语言模型每个位置都预测下一个 token 的目标不同。

5. NSP 的样本构造

原始 BERT 还引入 Next Sentence Prediction（NSP），希望模型学习两个文本片段之间的关系。每个训练样本由 A、B 两段构成：

  • 50% 的情况：B 是语料中紧接在 A 后面的真实后续片段，标签为 IsNext。
  • 50% 的情况：B 从语料中随机采样，标签为 NotNext。

论文把 A、B 称作“sentences”，但在实际样本构造中，它们可以是连续文本 span，不一定对应自然语言学意义上的单句。NSP 的二分类使用 [CLS] 位置的最终表示。

NSP 是原始 BERT 配方的一部分，不是所有 BERT 类模型必须保留的组件。后续 RoBERTa 在其更长训练、更大 batch、更多数据、动态 mask 等配方中移除了 NSP；这说明 NSP 的价值依赖训练设置，不能把后续整套 recipe 的结果简化为“NSP 已被证明永远无用”。

6. 预训练数据与训练流程

原始论文使用两个英文文档级语料：BooksCorpus（约 8 亿词）和英文 Wikipedia（约 25 亿词），合计约 33 亿词。作者强调保留文档级连续文本，以便采样较长的连续片段，而不是把句子完全打散。

论文报告 batch size 为 256 条序列，最大组合长度为 512 token，训练 1,000,000 步。为控制长序列的二次注意力成本，训练前 90% 的步数使用长度 128，最后 10% 使用长度 512；所以“256×512=128,000 token/batch”是最大长度下的算术值，并非每一步都使用 512 长度。

这些数字描述的是论文当时的训练设置，不是今天复现 BERT 的推荐默认值。硬件、实现、数据预处理、精度模式和优化器实现都会影响训练吞吐与最终结果。

7. 输入、编码器与预训练输出

输入端先构造 token、segment 与 position 三类 embedding 的和，再经过 LayerNorm 和 dropout，进入多层 Transformer encoder。每层输出维度保持为 H，因此可以堆叠。预训练时有两个输出分支：

  • MLM head：取被选中位置的 hidden state，映射到词表维度，预测原 token。
  • NSP head：取 [CLS] 位置的 hidden state，做 IsNext/NotNext 二分类。

预训练结束后，下游微调通常保留 encoder 参数，并按任务接入分类、序列标注或问答输出层。MLM head 与 NSP head 是预训练目标的输出接口，不意味着所有下游任务都必须继续使用它们。

8. MLM 带来的训练目标边界

MLM 让编码器在预测目标时使用左右上下文，但它也有代价：每一步只有 15% 的 token 位置承担直接预测损失，通常比每个位置都参与预测的自回归目标收敛更慢。论文的实验观察到 MLM 收敛略慢，但其下游表现提升抵消了额外训练成本。

另一个边界是：MLM 并没有定义自然的从左到右序列概率分解。因此标准 BERT encoder 不能直接当作 GPT 式的自回归文本生成器使用。模型目标与推理接口必须匹配。

关键结论

  • MLM 先选 15% 的 WordPiece 位置，再按 80/10/10 规则处理输入；损失只在被选位置计算。
  • NSP 用 50% 真实后续片段和 50% 随机片段构造二分类目标；它是原始 BERT 的配方，不是后续所有模型的必需项。
  • 原始训练采用 BooksCorpus 与 Wikipedia、1M 步训练，并在 90% 步数使用长度 128、最后 10% 使用长度 512。
  • MLM 学习深层双向表示，但不是自回归概率分解；标准 BERT encoder 不是生成式 decoder。
